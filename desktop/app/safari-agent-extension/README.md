# Agent Safari status-only candidate

`build-candidate.sh /path/to/Agent.app` copies an app into a new temporary directory, compiles and embeds the status-only native Safari Web Extension handler, signs the nested extension and candidate, and verifies both signatures. It never installs or launches anything. `SIGN` must be explicitly specified: `SIGN=-` is an ad-hoc structural test only, **not** the installed signing identity. For a certificate-signed candidate, specify the appropriate signing identity; the script checks its designated requirement against the input app and rejects mismatches. Certificate access may prompt or fail and has not been tested here. Never install the ad-hoc candidate.

The manifest requests only `nativeMessaging`. If enabled in the future, the background script attempts a native messaging connection and exposes only an exact, versioned capabilities query and a fixed-slot window status lookup. Production starts with an empty registry and provides no registration path, so it cannot look up any window. The offline fixture injects a registry to test a single-ID `windows.get` call with `populate: false`; responses omit window metadata. A matching ID is not proof of ownership or safe input routing. The handler accepts only an exact version-1 capabilities probe, never echoes, logs, or stores input, and has no window, tab, profile, account or input control. The existing Agent build/update path is intentionally unchanged: this candidate is not installed or registered. No Safari extension lifecycle, message routing, shared sessions, window behavior, permissions, placement or isolation has been demonstrated. Native messaging does not provide independent keyboard focus or all-app support.

Offline checks: run `SIGN=- safari-agent-extension/build-candidate.sh "$HOME/Applications/Agent.app"`; run `swiftc -module-cache-path /tmp/agent-safari-module-cache safari-agent-extension/MessagePolicy.swift tests/safari_message_policy_tests.swift -o /tmp/agent-safari-policy-tests && /tmp/agent-safari-policy-tests`. Real signing, enablement, and any live Safari test require separate evaluation and consent.

Offline JavaScript checks: `node tests/safari_window_discovery_tests.js`. These use mocks only; Safari API support, native message routing, extension lifecycle, registration and window identity, same-profile sessions, focus and noninterference remain unverified. No real Safari window or tab was inspected.
