# The browser extensions (browser/): the owner's own words

This is a spec. It holds only what the owner wrote, quoted exactly as typed, with the date (UTC) it was written. The
owner writes and maintains it; agents read it and never edit it. When code and a spec disagree, the spec wins, and where
two quotes disagree, the later one is the owner's current word. Each folder has at most one SPECS.md, holding the
decisions whose effect is that folder; decisions that affect all of Hive are in the root SPECS.md.
